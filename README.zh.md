# lazy-workspace-manager

[English](README.md) | 中文

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![DSH](https://img.shields.io/badge/DSH-0.2.1--rc.2%2B-4b6bfb)](https://github.com/deepseek-ai/deepseek-harness)

DeepSeek Harness（DSH）工作区懒加载与按需管理插件。

## 概述

在多工程场景下使用 DSH 时，系统会随工作目录切换累积大量工作区注册项。随着项目增多，侧边栏将全量罗列所有历史工作区及相关会话，增加检索与维护成本。

**lazy-workspace-manager** 提供工作区的**懒加载**与**自动管理机制**：
- **按需加载**：DSH 启动时不对历史工作区进行全量渲染，避免侧边栏随项目目录增加而无限膨胀。
- **自动归属与追溯**：恢复会话或打开指定会话时，自动追溯并加载其对应的工作区目录，避免会话因工作区未载入而进入“未分组”状态。
- **前端状态代理，无侵入性**：本模块主要对前端数据投影与交互流程进行代理，不修改底层持久化存储结构。**卸载或禁用模块后，系统即可完整恢复原版 DSH 的工作区加载与展示行为**。

---

## 主要功能

- **工作区按需加载**：侧边栏仅展示当前已载入的工作区目录及其会话。
- **上下文自动追溯**：激活或打开会话时自动定位并装载对应工作区，确保会话上下文与工作区结构保持一致。
- **默认工作区配置**：支持在配置界面设置随系统启动自动加载的高频工作区。
- **侧边栏卸载语义重定向**：侧边栏的“删除工作区”操作重定向为“卸载”（仅从视图中移除，不注销工作区及破坏数据）；实际注销流程统一收敛至设置页面并提供二次确认。
- **空白草稿与归档过滤**：自动过滤未产生交互的空白会话及已归档会话，保证界面整洁。
- **安全可逆**：模块停用或移除后立即恢复 DSH 官方全量加载逻辑，无遗留副作用。

## 运行环境

- DeepSeek Harness Web: **0.2.1-rc.2** 及以上版本。
- Node.js: **22.15+** 或 **24+**。
- 纯 JavaScript 实现，无构建流程及原生二进制依赖。

## 安装

### 通过 GitHub 安装

```sh
dsh plugin --profile web add "git+https://github.com/n431mn/lazy-workspace-manager.git#v1.0.0"
dsh web
```

*注：如需使用 main 分支最新版本，可移除末尾的版本标签。*

### 本地路径安装

```sh
dsh plugin --profile web add "link:D:/path/to/lazy-workspace-manager"
dsh web
```

安装并启动后，刷新浏览器页面，即可在 **设置 → 按目录加载** 中进行配置。

---

## 使用说明

1. **工作区管理**（路径：**设置 → 按目录加载**）：
   - 点击 **添加目录…** 选取工程路径，插件将自动完成注册并立即加载至侧边栏。
   - 通过目录卡片的操作开关，可随时对指定工作区执行**加载**或**卸载**。
   - 勾选 **启动时自动加载**，配置将持久化保存，系统启动及刷新时将保持常驻。
2. **侧边栏操作**：
   - 侧边栏的“删除工作区”仅执行卸载操作，不删除持久化数据。
   - 如需彻底移除工作区注册记录，请在设置界面中使用“删除注册…”操作。

---

## 卸载与恢复

如需恢复 DSH 默认的工作区全量展示逻辑，执行以下命令移除模块：

```sh
dsh plugin --profile web remove lazy-workspace-manager
dsh web
```

刷新页面后，所有工作区与会话即刻恢复官方默认展示逻辑。
